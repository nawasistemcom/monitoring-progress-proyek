# Monitoring Progress Proyek

Monitoring Progress Proyek merupakan bagian penting dalam pengendalian proyek perumahan. Dengan monitoring yang baik, manajemen dapat mengetahui apakah pekerjaan berjalan sesuai rencana atau mengalami keterlambatan.

## Mengapa Monitoring Progress Penting?

Banyak proyek mengalami keterlambatan karena masalah tidak terdeteksi sejak awal.

Dengan monitoring yang terstruktur, tim dapat:

- Membandingkan target dan realisasi
- Mengidentifikasi deviasi pekerjaan
- Mengontrol kinerja kontraktor
- Mempercepat pengambilan keputusan
- Mengurangi risiko keterlambatan proyek

## Data yang Perlu Dimonitor

### Progress Rencana

Target pekerjaan yang telah disusun dalam time schedule.

### Progress Aktual

Capaian pekerjaan aktual di lapangan.

### Deviasi Progress

Selisih antara progress rencana dan progress aktual.

### Kinerja Kontraktor

Monitoring produktivitas masing-masing kontraktor.

### Status Pekerjaan

- Belum Mulai
- On Progress
- Selesai

## Manfaat Monitoring Progress

- Mempermudah evaluasi mingguan
- Mengontrol keterlambatan proyek
- Menjadi dasar action plan
- Membantu Project Manager mengambil keputusan
- Mendukung sistem kerja modern
